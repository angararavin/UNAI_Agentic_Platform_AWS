Internal build note · api-server.js

One API surface. Not the platform.

UNAI Studio is the internal workbench — Agent Foundry, Playground, the login-gated UI. api-server.js is what a customer actually gets: a single, versioned, Bearer-token surface that runs an agent and hands back a decision with its reasoning attached, in plain English — nothing else on the platform is reachable from it.

Base URL /api/v1 Auth Bearer token, no cookie fallback Spec /api/v1/openapi.yaml

Endpoint reference

Everything a customer's backend calls. Full request/response schemas in openapi.yaml.

Agents & runs — the business-decision layer
GET/agentsList built-in and customer-created agents
POST/agentsCreate an agent from a capability manifest
POST/agents/{id}/runRun it — returns decisions[], each with a plain-English explanation
GET/runsLast 50 runs, summarized
GET/runs/{id}Re-fetch one run's decisions without re-running it
Data foundation & ontology
GET/ontologyCanonical concepts to author agents against
GET/connectionsData-foundation connectors + status
POST/connectionsRegister a connection (databricks · snowflake · bigquery · neo4j · llm)
Governance
GET/containmentSafety status + recent gated events
POST/containment/killKill switch — force every action to human approval
POST/containment/policySet the action policy — gated · deny · allow

The confidence score alone would have let this execute on its own. What actually stopped it: $56,256 exceeds the $50,000 value gate — a policy rule, not a confidence problem. A customer reading only the JSON gets a boolean; a customer reading explanation gets the sentence above, for free, in every response.

Quickstart

No packaged SDK ships yet — these are two direct, dependency-light calls against the real endpoints above. Swap in a generated client later without changing the wire format.

# pip install requests
import requests

BASE = "https://api.yourcompany.com/api/v1"
KEY  = "unai_••••••••••••••••"

r = requests.post(f"{BASE}/agents/disruption_response/run",
    headers={"Authorization": f"Bearer {KEY}"})
run = r.json()

for d in run["decisions"]:
    status = "autonomous" if d["autonomous"] else "needs sign-off"
    print(f"[{d['confidencePct']}% · {status}] {d['explanation']}")
// no dependency — fetch is global on Node 18+
const BASE = "https://api.yourcompany.com/api/v1";
const KEY  = "unai_••••••••••••••••";

const run = await fetch(`${BASE}/agents/disruption_response/run`, {
  method: "POST",
  headers: { Authorization: `Bearer ${KEY}` },
}).then(r => r.json());

for (const d of run.decisions) {
  const status = d.autonomous ? "autonomous" : "needs sign-off";
  console.log(`[${d.confidencePct}% · ${status}] ${d.explanation}`);
}
▲ Bearer keys are flat (UNAI_API_KEYS) — no per-key scoping, quotas, or expiry yet. Fine for a first customer or two; add a keys table before onboarding more.
