# ADMIN PANEL & CONTROL TOWER MANUAL
## Enterprise Operations, Policy Configuration, and System Management

**Version:** 1.2.0  
**Target Audience:** System Administrators, IT Operations, and Supply Chain Leads  

---

## 1. Overview & Architecture

The **Streamlit Control Tower & Admin Panel (`src/ui/app.py`)** provides unified administrative visibility into the 5 SAP supply chain AI agents. Built with clean SAP Fiori-inspired aesthetics, it enables administrators to monitor live executions, enforce governance, manage human approvals, review operational performance, and track technology upgrades.

---

## 2. Navigation Views & Functional Modules

### 2.1 🚀 Agent Investigation Cockpit
- **Purpose**: Direct real-time execution and inspection of any agent on curated or custom scenarios.
- **Controls**:
  - Agent Selector: Switch dynamically between Agents 01 through 05.
  - Scenario Selector: Populated from `demo_cases.csv` for each agent.
  - Run Button: Executes the compiled LangGraph workflow.
- **Dossier Components**:
  - **KPI Metrics Cards**: Real-time diagnosis, confidence score, execution latency, and economic exposure.
  - **State Machine Trace**: Visual indication of the 6-step LangGraph node execution.
  - **Deterministic Calculations Inspector**: Full JSON breakdown of raw mathematical formulas (ensuring zero hallucination).
  - **LLM Reasoning Card**: Displays the natural language rationale generated by local Ollama.
  - **Action Proposal & Approval Desk**: Single-click approval/rejection triggers for consequential transactions.

### 2.2 ⚖️ Human-in-the-Loop Approvals Desk
- **Purpose**: Central clearinghouse for all consequential actions proposed by agents.
- **Features**:
  - **Pending Approvals Tab**: Shows active tickets awaiting human authorization, including target object ID, proposed parameter changes, economic impact, and rationale.
  - **Action Controls**: Approve, Reject, or append reviewer notes.
  - **All Tickets Tab**: Searchable history table of historical approvals with reviewer timestamps.

### 2.3 📊 Timely Performance & SLA Reports
- **Purpose**: Real-time aggregation of agent operational efficiency, latency, and economic protection.
- **Metrics**: Total runs, overall accuracy percentage, average latency, and cumulative value protected.
- **Per-Agent Breakdown**: Detailed SLA table tracking runs, latencies, and accuracy by agent key.
- **Export**: One-click generation of formatted Markdown reports to `audit/reports/`.

### 2.4 🔭 Technology Radar & Advisory
- **Purpose**: Executive dashboard tracking market advancements across LLMs, runtimes, protocols, and team upskilling.
- **Quadrants**:
  1. Foundational Models (Ollama Gemma4/Llama3.2 vs Qwen 2.5 vs DeepSeek-R1 vs SAP GenAI Hub).
  2. High-Throughput Runtimes (vLLM / SGLang).
  3. Protocols (LangGraph Checkpointers & Model Context Protocol - MCP).
  4. Team Upskilling Roadmap (Planner training, LangGraph engineering, SAP CDS/BAPI skills).

### 2.5 📜 Compliance & Audit Trail
- **Purpose**: Immutable, append-only inspection log for IT compliance, auditing, and debugging.
- **Features**:
  - Real-time tabular event list with timestamp, event type, agent ID, case ID, and user ID.
  - Detailed JSON event inspector showing raw payloads, parameters, and before/after states.

## 3. Configuration & Operational Maintenance

All system-level thresholds are configured in `.env`:
* `OLLAMA_MODEL`: Target model for deep reasoning (`gemma4:latest`).
* `OLLAMA_FALLBACK_MODEL`: Fast classification model (`llama3.2:latest`).
* `ENABLE_WRITE_ACTIONS`: Set to `false` for simulation-safe mode (default).
* `FASTAPI_PORT`: REST API port (default: `8000`).
* `STREAMLIT_PORT`: Admin panel port (default: `8501`).
