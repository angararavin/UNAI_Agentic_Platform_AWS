UNAI Architecture

One adaptive agent, seven shared layers, a Mistral-centric and cloud-neutral stack. Domain behaviour is added as lightweight tool packs — never as new agents.

UThe name — UNAI (oo-NYE)

Basque for “shepherd” — one who guides the many; it also reads literally as “one + AI.” And as two words, “Un AI” = “One AI” (in French/Spanish un = one) — reinforcing the thesis. Four readings, one idea: many become one. Brand rule: always one word, UNAI, so it never reads as the prefix “un-”. “UNAI” is always written as one word.

?How to read this — where the "many → one" saving comes from

Every AI agent secretly does the same seven things: senses data, remembers, reasons, weighs evidence, acts, talks to peers, and explains itself. In the old way, each new agent re-builds all seven. Here the seven are the green layer row — built once and shared. The only thing that changes per use case is a small purple tool pack (e.g. "inventory"). The amber ontology bar is the universal translator: it learns each system's field names once (MATNR, sku_id…), so the agent speaks one language to every system. That's the whole trick — the expensive 90% is shared; only the cheap 10% is per task.

Platform architecture — current build

The full runtime: the Agent Foundry (build · convert · compose · marketplace) registers agents onto a single shared cognitive runtime (seven layers, built once) with thin tool packs; a model-neutral LLM router + economizer; the canonical ontology plus a persisted Neo4j ontology store; the Supply-Chain Cognition Layer (learning ontology library · causal world model · self-onboarding — the differentiation moat); and governed warehouse & live-tool connectors. Governance, explainability and observability wrap every layer.

Canonical ontology layer — many dialects, one shared language

Each system speaks its own dialect; every native field is mapped once into a shared canonical concept. Hover a concept to isolate its sources. The agent only ever asks for the canonical concept — so moving between systems costs no re-mapping.
